# Group Tactics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generic squad tactics (group, tactics as data, goals, squad leader with own memory, goal keeper, area-to-path-cost adapter) in `sagax-decide`, in Rust, C and WASM/JS.

**Architecture:** New module `crates/sagax-decide/src/group/` with one file per block, integer only, caller-given `u32` time. The `Squad` owns its `Group`, a leader `Knowledge`, an `Areas`, an `Inbox` for reports and an order outbox; it scores `(tactic, target)` pairs with the existing `Decider` machinery and hands out `Goal`s as `Order` messages. Members keep using their own `Decider`; the group only gives them inputs.

**Tech Stack:** Rust (workspace), `sagax-ffi` (C, `include/sagax.h`), `sagax-wasm` + `js/sagax.mjs`, Node tests via `js/run.sh`.

**Spec:** `docs/superpowers/specs/2026-11-12-group-design.md` (read the sections "Decisions after review" and "Feedback from a game team" — they override earlier text).

## Global Constraints

- Time: caller `u32`, all ages `now.wrapping_sub(since)`; every duration in the same caller unit.
- Random effects only from the caller seed via `mix(seed ^ member_index ^ now)`; no global RNG, no floats.
- Ties: lower index wins (slot order, member slot order, spot index, target index).
- Capacities fixed at creation; capacity 0 → `ZeroCapacity` (Rust) / null (C).
- Existing public types stay unchanged: `Message`, `Decider`, `Areas`, `Knowledge`. Only additions.
- Public repo: no game names; roles are bit numbers; docs say "ranged", "area", "guard", "officer".
- Version 0.8.0, `API_VERSION = 8`. CI: `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `js/run.sh`, `examples/c/run.sh` (no local C compiler: rely on GitHub CI for C).
- Commits: author `STARSCrazy <STARSCrazy@users.noreply.github.com>` (set `GIT_AUTHOR_*` and `GIT_COMMITTER_*`), English messages, one commit per task.
- Square and hex: every geometry test also runs with `Metric::Hex`.

## Review Focus

- Leader dies mid-plan: plan and goals stay, new leader = next active slot, no replan by itself → test in Task 4.
- Suspended member: never "off plan", never "goal broken", skipped by assignment, keeper paused → test in Task 1 and 5.
- No candidate spots / all tags 0: every shipped tactic still assigns (nearest free spot, else wish point flagged unchecked) → test in Task 2.
- Time wrap (`issued_at` near `u32::MAX`): think time, max_wait and give-up still correct → test in Task 4 and 5.
- Target unknown to the leader (only in the caller's true world): never chosen → test in Task 3.

### Task 4: Squad running (orders, check, leader loss, signal)

**Files:** Create `group/orders.rs`; modify `group/squad.rs`.

**Interfaces — Produces:**
- `pub struct Order { pub member: u32, pub goal: Goal }` (new type; `Message` untouched).
- `pub enum Channel { Shout { range: i64 }, Radio { base: u32, per_unit: u32 }, None }`; `set_channel(member_id, Channel)`; shout: delay `arrival(now, 0, d, 1)`-style with `d` from leader, out of range → not delivered; radio: `arrival(now, base, d, per_unit)`.
- A new plan becomes active at `now + think_ticks`; then orders go out; `pub fn orders_due(&mut self, now, out: &mut Vec<Order>)`.
- `pub fn check(&mut self, now, extra: &[i32], spots, seed) -> Status` with `pub enum Status { Keep, Replan(PlanId), Signal, NoPlan }` — replan when an `Abort` fires or another candidate beats the active one by more than `hold_bonus`.
- Leader loss: `set_gone(leader)` → next active member in slot order becomes leader; active plan and goals stay; loss counts in `IN_LOSSES` only.
- `pub fn report(&mut self, msg: Message, arrive_at: u32)` (into the Squad `Inbox`; kinds `REPORT_GOAL_BROKEN`, `REPORT_ENEMY`, `REPORT_DANGER` with `data` = shooter pos index into `Areas` source); `pub fn observe(&mut self, fact: Fact, now)` (leader's own sight); `pub fn signal(&mut self, now)`; `pub fn arrived(&mut self, member_id, now)`.
- Trigger `AllArrived { max_wait }`: signal when every assigned active member called `arrived`, or `max_wait` after the gather orders went out. Timing spread: member start delay `= mix(...) % (timing_spread+1)`.

- [ ] **Step 1: Failing tests:** `plan_waits_think_ticks`, `radio_delay_by_distance`, `shout_out_of_range_not_delivered`, `hold_bonus_prevents_flicker`, `abort_rule_replans`, `leader_death_keeps_plan` (orders unchanged, new leader, `check` → Keep), `report_only_after_arrival` (danger area visible to `plan` only after `arrive_at`), `flank_gather_then_simultaneous_attack` (all arrive → one Signal; same tick for all), `flank_max_wait_fires_signal`, `think_time_wraps`, `weak_timing_spread_seeded`.
